Statistics consist of seven parts : Visitas, Páginas Vistas, Rastreamento, Origem, Configurações, Indicações, Summary, available for the period Dia, Semana, Mês, Year

phpMyVisites can for example gives these informations : Estatísticas, Visitas, Visitantes únicos, Páginas vistas, Páginas por visitante, Pages per visit, Pages per significant visit, Duração média de visita, Tempo médio por página vista, Taxa de visitas de uma página, Average visits per day

phpMyVisites has a powerful administration tool. For example you can :

  • Você pode excluir o Administrador das estatísticas. Este método é baseado em cookies e esta opção só vai funcionar com este browser. Você pode mudar essa opção à qualquer hora.
  • Don't count IP/IP ranges in the statistics
  • Record ALL URL variables / Do NOT record any URL variable / Record ONLY specified variables / Record all EXCEPT specified variables
  • Add newsletter / Add partner / Add site
  • Send statistics by email / Statistics in a RSS feed
  • Server Information
